# Архитектура VTS (Voice Task System)
*Архитектура информационной системы управления задачами на основе голосового ввода*

Автор: Токмаков Игорь 

Группа: РИС-22-2

## Описание системы
Разрабатываемая система представляет собой интеллектуальную платформу, предназначенную для автоматизации процесса постановки и сопровождения задач с использованием голосового интерфейса. Основная цель системы обеспечить пользователю максимально удобный и естественный способ формирования списка задач и работы с расписанием без необходимости ручного ввода.

Целевая аудитория: предполагается использование системой от несколькими десятками до нескольких сотен пользователей, активно управляющих личными и рабочими задачами (студенты, специалисты, менеджеры проектов, фрилансеры).

Требования к системе
- Пользователь создаёт задачу голосовой командой, произнесённой на русском языке.
- Система распознаёт речь и извлекает из неё:
	- название задачи,
    - дедлайн,
    - дополнительные параметры (например, напоминания).
- На основе интерпретированного текста Rule Engine автоматически принимает решения:
    - нужно ли поставить напоминание,
    - когда отправить уведомление,
    - какие поля задачи заполнить,
    - выполнять ли синхронизацию с календарём.
- Пользователь может создавать, редактировать и удалять правила для Rule Engine через веб-интерфейс или админ-панель.
- Пользователь может включить одностороннюю синхронизацию задач с Yandex Календарём.
- Система предоставляет минималистичный веб-интерфейс для просмотра, редактирования и фильтрации задач.
- Система создает уведомления и напоминания для привязанных сервисов (Telegram, e-mail).

Дополнительный контекст:
- В условиях роста рынка инструментов цифровой продуктивности голосовые интерфейсы становятся значимым фактором повышения удобства и эффективности пользовательского взаимодействия.
- Рынок персональных ассистентов активно развивается, однако существующие решения часто предлагают либо поверхностный голосовой ввод без интеллектуальных правил, либо наоборот, полноценные профессиональные инструменты продуктивности, но без естественного голосового интерфейса.
